# Mental Health Score Prediction

A Machine Learning web application that predicts a user's **Mental Health Score** based on demographic, academic, lifestyle, and social media usage data. The project combines a trained Scikit-learn model with a FastAPI backend and a modern responsive frontend.

## Features

* Predicts Mental Health Score using a trained ML model
* FastAPI REST API for inference
* Responsive HTML, CSS, and JavaScript frontend
* Input validation using Pydantic
* Clean project structure for easy deployment

## Tech Stack

* Python
* Scikit-learn
* Pandas
* NumPy
* FastAPI
* Pydantic
* HTML
* CSS
* JavaScript
